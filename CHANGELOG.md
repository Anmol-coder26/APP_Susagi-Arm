## [3.0.0] - 2026-11-24

### Added
* **Contextual Scam Intelligence:** Astra requested-action analysis engine distinguishing benign personal discussion from advance-fee extortion.
* **ExecuTorch Llama Integration:** Native JNI integration (`org.pytorch:executorch-android:1.5.1`) with ARM64 NEON acceleration for on-device reasoning.
* **Conversational Knowledge Engine:** Fault-tolerant on-device fallback providing real-time streaming guidance when model weights are unprovisioned.
* **Offline Extortion Simulation Harness:** Integrated in-app testbed running 7-turn CBI digital arrest scenarios with live waveform radar and SOS alerts.
* **Link & Sideload Shield:** Real-time domain entropy, Unicode Punycode/homoglyph unmasking, and anti-sideload `.apk` download interception.
* **UPI & QR Reverse-Debit Guard:** Hardcoded financial safety invariant ensuring entering a PIN always flags collect requests claiming cashback.
* **Private Incident Store:** Encrypted local SQLite Room database with automated PII and credential masking.
* **Automated Test Suite:** 315 verified unit and regression tests across 51 test suites with 0 failures.

### Changed
* Updated Target SDK to Android 15 (`API 35`) and Min SDK to Android 8.0 (`API 26`).
* Synchronized product branding to clean, competition-independent open-source standards.
* Reorganized documentation into modular, maintainable technical directories.
